# Downloader PDSI - Local

Sistema local de download e processamento de áudios do YouTube com segmentação e normalização.

## Status
Em desenvolvimento - Branch: downloader_local

## Funcionalidades Planejadas
- Download de áudios (vídeos, playlists, canais)
- Segmentação de áudio
- Normalização com SOX
- Extração de metadados
- Sistema de skip inteligente
- Suporte a batch de links

## Estrutura
```
downloader_PDSI/
├── config.py
├── input/
├── output/
├── logs/
└── src/
```

## Dependências
- Python 3.8+
- yt-dlp
- pydub
- SOX (sistema)
